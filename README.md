## Anush Bharathi R

I work on finding and rebuilding editable CAD models, and on using geometry to check parts during design and inspection. I'm at IIT Madras, in the ADOPT Lab and the Advanced Geometric Computing Lab.

**Projects, papers and videos: [exanos.github.io](https://exanos.github.io)**

### Research

- **MM-CAD**: a public dataset of 226K CAD models, each with a B-rep, point cloud, text, sketches and images, and a benchmark for searching across them. *Computer Graphics Forum* 45(5), SGP 2026, first author.
  [Paper](https://doi.org/10.1111/cgf.70523) · [Dataset](https://huggingface.co/datasets/exanos/MMCAD) · [Code](https://github.com/exanos/MMCAD) · [Talk](https://www.youtube.com/watch?v=3-a2MjjOJT0)
- **Abra-CAD** (under review, first author): rebuilds an executable CadQuery program from a mesh, point cloud, B-rep or drawing, and checks it in the CAD kernel.
  [Project page](https://exanos.github.io/projects/abra-cad.html)
- **Busbar design system for TE Connectivity**: engineers and a locally hosted LLM edit one design state, and a geometry solver checks every change before Creo Parametric rebuilds the part.
  [Project page](https://exanos.github.io/projects/te-busbar.html)
- **CAD-RAG**: retrieving and generating editable CAD. *Journal of WSCG*, 2025.
  [Paper](https://doi.org/10.24132/JWSCG.2025-11) · [Project page](https://exanos.github.io/projects/cad-rag.html)
